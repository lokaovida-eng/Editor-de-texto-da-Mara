## ✨ Key Features & Capabilities

- ✍️ **Rich Text Formatting**: Full support for bold, italic, underline, custom fonts, text alignment, and font scaling.
- 🖼️ **Inline Image Embedding**: Insert photos, diagrams, and illustrations directly into document pages.
- 📄 **Direct PDF Export**: Convert and save rich documents as standard PDF files locally with a single tap.
- 🖨️ **Direct Android Printing**: Integrated with the Android Print Service to print documents wirelessly to any paired printer.
- 💾 **File Management**: Save, edit, and organize local document drafts efficiently.
